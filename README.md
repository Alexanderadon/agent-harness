# hackalem-env

Окружение команды Lomra для HackAlem AI (23.09.2026). Здесь нет кода под задачу, только конвенции,
скиллы для агентов-разработчиков, шаблоны документов и план дня. Всё одинаково применимо к любому
из 30 кейсов, поэтому это harness, а не заготовка (Положение 6.4, 6.9).

Текст для раздела README «Использованные внешние материалы» на самом хакатоне:

> До старта подготовлены и опубликованы общие материалы команды (репозиторий hackalem-env, коммиты до 23.09.2026):
> конвенции AGENTS.md, шаблоны README/SPEC/PROGRESS, дизайн-токены, чеклисты. Весь код проекта написан
> во время соревновательной части в репозитории, созданном платформой. Использованы Claude Code и Codex.

## Что внутри

- `AGENTS.md`, `CLAUDE.md` — конвенции для Claude Code и Codex. Копируются в корень проекта в первые 10 минут.
- `skills/*` — скиллы: агент на AI SDK v7, консоль агента, README под рубрику, скрипт verify, дизайн-проход, деплой, security-pass.
- `templates/*` — README, SPEC, PROGRESS, `.env.example`, дизайн-токены для `globals.css`.
- `codex/config.toml` — конфиг Codex для ноутбука.
- `WINNING-SHAPE.md` — универсальная форма продукта под рубрику и как за 15 минут натянуть на неё любую задачу.
- `DAY-PLAN.md` — план 5 часов по блокам с промптами и ролями.
- `REHEARSAL.md` — репетиция на 2 часа на чужом домене.
- `LAPTOP.md` — чеклист ноутбука: инструменты, логины, ключи, какие публичные репозитории можно использовать.

## Установка на ноутбук

```powershell
git clone https://github.com/Alexanderadon/hackalem-env
cd hackalem-env
.\install.ps1
```

Скрипт копирует скиллы в `~/.claude/skills`, конфиг в `~/.codex/config.toml` (старый сохраняется как `.bak`).
Шаблоны и AGENTS.md копируются в репозиторий проекта вручную после старта.
