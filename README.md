# agent-harness

Универсальное окружение для разработки агентных веб-продуктов с AI-инструментами (Claude Code, Codex) в 2026 году:
конвенции для агента-разработчика, скиллы, шаблоны документов, дизайн-токены, конфиги. Кода продукта здесь нет,
всё одинаково применимо к любому проекту: хакатон, пилот для заказчика, личный продукт.

Стек по умолчанию: Next.js 16, TypeScript strict, Tailwind v4, shadcn/ui, Vercel AI SDK v7, zod, libSQL (файл локально, Turso в облаке), vitest, pnpm, Vercel.

## Что внутри

- `AGENTS.md`, `CLAUDE.md` — конвенции для Claude Code и Codex: стек, структура, контракт, агент с подтверждением записи, стиль, надёжность, безопасность, что считается готовым.
- `skills/` — скиллы для агента-разработчика:
  - `scaffold` — скаффолд Next.js 16 + shadcn + AI SDK без единого вопроса, внутри непустого репозитория.
  - `ai-sdk-agent` — агент на AI SDK v7: ToolLoopAgent, инструменты с zod, подтверждение записи, стрим в интерфейс, тесты с мок-моделью, модели и цены.
  - `agent-console` — экран «таблица слева, агент с трейсом и Approve справа, Reset».
  - `readme-rubric` — README, по которому проект можно оценить и запустить без автора.
  - `verify-script` — `pnpm verify`: доказательство, что основной сценарий работает.
  - `deploy-first` — Vercel через CLI, Turso, смоук с телефона.
  - `design-pass` — 15-минутный визуальный проход по фиксированной формуле.
  - `security-pass` — 10-минутная проверка безопасности и надёжности перед сдачей.
- `templates/` — README, SPEC, TASK (условие дословно), TASKS (чеклист блоков), PROGRESS, KICKOFF-PROMPT (что писать агенту), `.env.example`, дизайн-токены для `globals.css`.
- `codex/config.toml` — конфиг Codex.
- `install.ps1` — раскладывает скиллы в `~/.claude/skills` и конфиг в `~/.codex`.
- `playbooks/hackalem-2026/` — плейбук под конкретное событие, HackAlem AI 23.09.2026: карта действий (MAP), CONTEXT (память для агента на ноутбуке), PICK-TASK (выбор задачи в 13:30), план дня, форма продукта под рубрику (WINNING-SHAPE), репетиция, чеклист ноутбука, бюджеты мощности, DEMO-DAY (открывать после 23-го). Следующее событие получает свою папку рядом.

## Установка

```powershell
git clone https://github.com/Alexanderadon/agent-harness
cd agent-harness
.\install.ps1
```

В репозиторий проекта копируются `AGENTS.md`, `CLAUDE.md` и нужные шаблоны из `templates/` (см. `templates/KICKOFF-PROMPT.md`, шаг −1).
