## Воспроизводимость и запуск

**Системные требования.** Node.js 22 (файл `.nvmrc`), pnpm 10, любая ОС. Сеть нужна только для установки пакетов и вызовов модели. Отдельная база данных не нужна: SQLite-файл создаётся сам.

**Зависимости.** Все в `package.json`, версии зафиксированы в `pnpm-lock.yaml`. Нативные модули (`@libsql/client`) собираются автоматически, список в `pnpm.onlyBuiltDependencies`.

**Переменные окружения** (`.env.example`):

| Переменная | Обязательна | Зачем |
|---|---|---|
| `OPENAI_API_KEY` | для агента | вызовы модели; без ключа приложение работает в режиме просмотра данных |
| `NVIDIA_API_KEY` | вместо `OPENAI_API_KEY` | тот же код через OpenAI-совместимый эндпоинт NVIDIA; тогда `AGENT_MODEL` обязателен |
| `AGENT_MODEL` | нет | модель, по умолчанию `gpt-6-sol`; для NVIDIA id модели с build.nvidia.com |
| `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN` | нет | облачная база для развёрнутой версии; локально не нужны |

## Базовая надёжность и безопасность

- Все входы API проверяются zod-схемами; невалидный запрос получает 400 с описанием.
- Ошибки модели и инструментов ловятся и показываются в панели, приложение не падает.
- Лимиты: 6 шагов на запуск, `maxDuration = 60`, размер ввода ≤ {{N}} символов.
- Секреты только в env; `.env.example` без значений; ключи в репозитории отсутствуют.
- Записи в базу выполняются только после явного подтверждения пользователя.
- В приложении нет заранее подготовленных ответов модели: каждый Run это живой вызов модели с инструментами. Мок-модель (`MockLanguageModelV4` из `ai/test`) используется только в `tests/agent.test.ts`; без ключа маршрут агента отвечает 503, а не имитацией.
- `scripts/verify.ts` подтверждает запись автоматически (`toolApproval: approved`) только внутри скрипта проверки; в приложении такого пути нет, подтверждение всегда от пользователя.
