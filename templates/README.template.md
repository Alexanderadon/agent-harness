## Воспроизводимость и запуск

## Базовая надёжность и безопасность

- Все входы API проверяются zod-схемами; невалидный запрос получает 400 с описанием.
- Ошибки модели и инструментов ловятся и показываются в панели, приложение не падает.
- Лимиты: 6 шагов на запуск, `maxDuration = 60`, размер ввода ≤ {{N}} символов.
- Секреты только в env; `.env.example` без значений; ключи в репозитории отсутствуют.
- Записи в базу выполняются только после явного подтверждения пользователя.
