## Правила, которые нельзя нарушить (Положение, ред. на 23.09.2026)
Разработка только в Репозитории, созданном платформой; он же единственный основной рабочий репозиторий, в нём подтверждаемая история (5.4.9, 5.4.11).
Подтверждённый промежуточный результат **каждый час** (5.4.8).
Раскрыть заранее подготовленные компоненты (5.4.4–5.4.6). Заранее сделанные шаблоны, свои библиотеки и инфраструктура **разрешены явно** (5.4.4.2), если это не готовый продукт и не основная часть решения; основная функциональность пишется в соревновательной части (5.4.5). Наш agent-harness под это попадает, коммит скаффолда помечается «disclosed».
Любые AI-инструменты разрешены, Codex не обязателен (5.4.12).
**Итоговая версия — содержимое репозитория на 18:00**, независимо от момента блокировки интерфейса платформы (5.4.13). Изменения после 18:00 не учитываются (5.4.14). Последний пуш планировать на 17:45.
**Не запускается по README — снятие с отбора** (5.4.16, 5.6.5). Не потеря баллов, а недопуск; пояснения и исправления не принимаются.
**Проверка без наших аккаунтов (5.6.6).** Ключевая функциональность должна проверяться без личных аккаунтов, подписок и закрытых учёток участников; при использовании внешних API нужно дать демо-доступ или тестовую учётку. Живой URL с ключом на стороне сервера — обязанность, а не бонус. Ветка «режим просмотра без ключа» этому пункту не удовлетворяет.
README обязан содержать (5.4.15): описание решения и назначения, архитектуру, технологии, установку, запуск, зависимости, параметры окружения, порядок проверки основного сценария.
Присутствие на площадке обязательно, суммарное отсутствие больше 60 минут — дисквалификация (5.1.7.1).
