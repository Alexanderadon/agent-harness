# Эмина · день хакатона на одном экране

У тебя свой агент на своём ноутбуке: Codex или Claude Code, открытый в клоне репозитория команды. Ему ставится скилл `captain`
(через install.ps1 из agent-harness). Ты пишешь ему команды в одно слово, он делает документы и данные, коммитит и пушит под твоим аккаунтом.
Код ты не трогаешь, и агент твой тоже: он имеет право только на README.md, PROGRESS.md, docs/ и data/test-cases.*.
Если агент не поднялся, всё то же самое делается руками через сайт GitHub с телефона: карандаш «Edit», «Commit changes».

## Команды твоему агенту
| Когда | Пишешь | Что делает |
|---|---|---|
| 0:00, первое сообщение | `Я Эмина` | агент включает роль капитана, проверяет, что коммиты пойдут под твоим именем, показывает команды |
| 0:05, задача выбрана | `task` (и вставляешь текст условия) | сохраняет условие дословно в docs/TASK.md, коммит |
| :55 каждого часа | `progress` | строка в PROGRESS.md из истории коммитов обоих, коммит |
| 0:40, если условие требует набор данных | `testdata` | data/test-cases.json и описание, коммит |
| 1:30 и 3:15 | `readme` | README по шаблону из того, что реально есть в коде; вопросы Александру списком |
| 3:40 | `audit` | проверяет каждое утверждение README по файлам, противоречия удаляет |
| 4:20 | `submit` | docs/SUBMISSION.md для анкеты в кабинете |

Перед каждой командой агент сам делает `git pull`, после каждой сам пушит. Ничего про git тебе знать не надо.

## До старта
- На ноутбуке: Node 22, pnpm 10, Git, Codex или Claude Code, `git clone` репозитория команды, из agent-harness `.\install.ps1 -Role emina`. Роль записывается в настройки агента: он выполняет только твои команды и не трогает код, даже если попросить. Один раз до 22-го проверить, что команда `progress` на тестовом репозитории работает.
- 12:30 перки: ключ API в менеджер паролей, второй туда же как запасной.
- Методика оценки и порядок отбора: прочитать первой, пересказать Александру три вещи: условия допуска, требуемые материалы, дедлайн.

## 13:30–13:45 · выбор задачи
- Тексты задач своего трека и соседних в один файл, прогнать через промпт из `PICK-TASK.md` в своём ChatGPT или Claude, принести рейтинг. Первая без красных флагов, спор дольше 10 минут запрещён.
- `task` с текстом выбранной задачи. Это твой первый коммит.

## Между командами
- **Ментор партнёра.** Найти представителя компании-заказчика на площадке, один вопрос: «что заставит вас запустить пилот завтра?». Ответ в README, в ограничения и требования.
- **Живой URL.** Раз в час открыть в инкогнито на телефоне: таблица видна, Run работает. Что не работает, Александру одной фразой.
- **README как читатель.** После каждого `readme` прочитать глазами судьи без контекста; непонятное и обещанное, но невидимое в интерфейсе, сказать Александру словами.
- **Оргвопросы.** Всё от организаторов и проверяющих на площадке это к тебе, Александра не дёргать.

## 4:15 · ты судья
- В новой папке: `git clone` репозитория команды, дальше строго по README без вопросов Александру: `pnpm install`, `pnpm dev`, localhost, Reset, Run, Approve.
- Дошла до конца, значит судья дойдёт. Не дошла, говоришь шаг, Александр чинит это, а не добавляет новое.

## 4:30–4:40 · подача
- `submit`, потом анкета в кабинете черновиком к 4:30. В 4:40 после «ок» от Александра отправить. Опоздание это дисквалификация.

## Чего не делать
- Не коммитить ничего до 13:30. Не давать свой аккаунт Codex Александру, не брать его.
- Не править код и не просить агента править код: просьбы к коду только строкой в TASKS.md, раздел requests.
- Не предлагать вторую фичу. Одна задача, один сценарий, до конца.
