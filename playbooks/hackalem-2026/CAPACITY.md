## Как тратить, чтобы хватило и не осталось лишнего
1. Claude Code на самой сильной модели плана, без экономии: это главный ресурс дня. Уровень усилий high только на блоки 3–4 (агент), остальное medium.
2. Всё, что не требует твоей головы, уходит в Codex параллельно: черновик README в 1:30, тесты в 2:50. Это не расходует окно Claude и экономит час стены.
3. Если Claude показал предупреждение о лимите: доделать текущий блок, `/clear`, дальше Codex CLI на том же репозитории с тем же AGENTS.md. Не ждать сброса окна.
4. Модель продукта: `gpt-5.6-luna` весь день, `gpt-5.6-terra` в Vercel перед финальным деплоем. `gpt-6-astra` только на один вызов вне цикла, если задача требует анализа. Один прогон на terra стоит около 9 центов, на astra в цикле около 40; за день нужно 300–400 прогонов.
5. Ключ Б не участвует в разработке. Он живёт в Vercel как fallback и гарантирует судьям рабочий продукт, даже если ключ А исчерпан.
6. Контекст держать маленьким: `/clear` на границах блоков, файлы вместо пересказов, хвост логов 50 строк. Большой контекст съедает окно быстрее, чем количество сообщений.
