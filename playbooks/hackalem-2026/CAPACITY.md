4. Модель продукта: локально весь день `gpt-6-luna`. В Vercel production модель выбирается на деплое 2:50: `gpt-6-sol`, если 3 из 3 Run на URL < 30 с с карточкой Approve и баланс lomra-demo ≥ $10; иначе `gpt-6-luna`; иначе `gpt-5.6-terra`. После 3:15 не меняется. `gpt-6-astra` только на один вызов вне цикла, если задача требует анализа. `AGENT_REASONING` по умолчанию low; уровни мерить на деплое 1:50 (3 Run на URL; все быстрее 15 с — medium через `vercel env` и `vercel redeploy`), не в 1:40: там агент уже начинает блок 4. Прогон на sol стоит около 8 центов, на astra в цикле около 40.
5. Ключ lomra-demo не участвует в разработке. Он живёт только в Vercel production; суточный предохранитель `AGENT_RUNS_PER_DAY` (300) защищает от злоупотребления, а от перерасхода — предоплата без автопополнения.
6. Контекст держать маленьким: `/clear` на границах блоков, файлы вместо пересказов, хвост логов 50 строк. Большой контекст съедает окно быстрее, чем количество сообщений.
