# 05 · Оценка системы и дыры

Честная оценка связки «два ноутбука, два агента, один репозиторий» на 21.09.

## Что крепко

- **Разделение по файлам, а не по задачам.** Код у Александра, документы и данные у Эмины. Конфликты в git невозможны по построению, а не по договорённости.
- **Синхронизация через репозиторий, а не через людей.** Оба агента делают pull перед каждой командой и читают доску TASKS.md. Просьбы друг другу это строки в файле, обрабатываются на границах блоков.
- **Команды в одно слово.** Длинный текст живёт в скиллах, человек не может отправить агенту неправильный промпт, потому что не пишет промпты.
- **Роль по имени.** `Я Александр` и `Я Эмина` включают роль и проверяют git-имя. Команды чужой роли не выполняются.
- **Чекпоинт, который нельзя провалить.** Пушится всё, даже красное. Её агент замечает час без коммитов у него.
- **Один источник данных.** Черновик сида от Эмины принимается в data/seed.json, судья видит один набор данных, а не два.
- **Судья внутри команды.** Проверка в 4:15 на чужом ноутбуке по README, без контекста автора.
- **Заложенные чужие ошибки.** Autostash, запрет force push, eol=lf, serverExternalPackages, память вместо файла на Vercel, dev не в терминале агента, путь без кириллицы. Список в `PITFALLS.md`.

## Где тонко

| Дыра | Насколько опасно | Чем закрыто | Что остаётся |
|---|---|---|---|
| Codex на ноутбуке Эмины может не подхватить скилл из `~/.codex/skills` | средне | запасной путь: вставить текст SKILL.md первым сообщением; проверка до старта | проверить один раз |
| У Эмины может не быть права записи в репозиторий команды | высоко | проверка карандаша «Edit» до 22-го, письмо организаторам, запасной путь через co-author | сделать проверку |
| Codex CLI требует Plus или Pro; без подписки до 12:30 репетиция агента у Эмины невозможна | средне | окно 12:35–12:55 на первую проверку с перк-аккаунтом | заложено в план |
| Имена API AI SDK v7 в скилле проверены по документации, а не запуском | высоко | правило «открой node_modules, не гадай» | только репетиция |
| Turso с libsql на Vercel не запускался ни разу | средне | fallback в память, деплой не обязателен по рубрике | только репетиция |
| Подтверждение инструмента через useChat не запускалось ни разу | высоко | точные имена состояний в скилле | только репетиция |
| Оба агента правят TASKS.md | низко | свои строки, правило слияния в обоих скиллах | |
| Часы на одном ноутбуке, у Эмины их нет | низко | её команда `progress` привязана к :55, Александр говорит вслух «чекпоинт» | |
| Лимит Claude к четвёртому часу | средне | Codex с той же ролью на том же ноутбуке | |

## Что закрывает только репетиция

Четыре неизвестных, и все в коде, не в документах: имена API AI SDK v7, Turso на Vercel, подтверждение через useChat, чистый клон по README. Час прогона на любом чужом домене закрывает все четыре. Без него первое знакомство с ними случится в блоках 3–6 в день хакатона, и каждое стоит 30–60 минут.

## Оценка

По документам система на уровне команд, которые делают это не первый раз. По коду она не проверена вообще. Ожидание технического балла: 82 с репетицией, 65 без, разброс в обе стороны 10–15. Что двигает к 90: репетиция, задача с четырьмя требованиями, README после аудита, живой URL в инкогнито.
