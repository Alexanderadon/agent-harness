# 03 · Эмина: что нажимать и что писать

Твоя роль: капитан. Задача, документы, данные, организаторы, проверка как судья, подача. Кода ты не касаешься, и твой агент тоже. Ты пишешь ему команды в одно слово, он пишет файлы и сам отправляет их в репозиторий под твоим именем.

## До 22-го, по порядку

1. На ноутбуке: Node 22, pnpm 10, Git for Windows, Codex CLI (`npm i -g @openai/codex`), VS Code. В PowerShell один раз: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
2. Git с твоим именем: `git config --global user.name "Эмина Ануарбекова"` и `git config --global user.email "почта твоего GitHub"`. Один тестовый `git push` в любой свой репозиторий, чтобы Windows запомнил вход.
3. Комплект: `git clone https://github.com/Alexanderadon/agent-harness`, в папке `.\install.ps1 -Role emina`.
4. Проверка права записи: открыть https://github.com/BAITC-Hacks/hack-463fe33c-lomra под своим аккаунтом. На README виден карандаш «Edit» и кнопка «Add file». Не видно: до 22-го написать организаторам, чтобы добавили твой аккаунт.
5. `git clone https://github.com/BAITC-Hacks/hack-463fe33c-lomra` в `C:\hack\`. Только клон, ничего не отправлять.
6. Проверка агента: в папке клона запустить `codex --full-auto`, написать `Я Эмина`. Должны прийти четыре строки: роль, твоё git-имя, ветка, список команд. Если Codex не видит скилл, первым сообщением вставить текст файла `skills/captain/SKILL.md` из комплекта, потом `Я Эмина`.
7. Один раз пройти путь судьи на любом проекте: `git clone`, `pnpm install`, `pnpm dev`, открыть localhost. Просто чтобы руки помнили.
8. Прочитать `PICK-TASK.md` из комплекта: там шесть вопросов к задаче и промпт.

## Если агент на ноутбуке не работает

Всё то же самое руками с телефона через сайт GitHub: открыть файл, карандаш «Edit», текст, «Commit changes». Условие в docs/TASK.md, строка в PROGRESS.md каждый час. README тогда пишет агент Александра по его просьбе, а ты читаешь.

## Чего не делать

- Ничего не отправлять в репозиторий до 13:30.
- Не давать свой аккаунт Codex Александру и не брать его: каждый пользуется своим.
- Не просить агента править код. Просьба к коду это строка в TASKS.md в разделе requests, агент сам её напишет, если сказать «попроси Александра: …».
- Не предлагать вторую фичу. Одна задача, один сценарий, до конца.
- Не отвечать за Александра на технические вопросы проверяющих: записать вопрос, передать ему на границе блока.
