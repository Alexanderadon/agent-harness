## Если ломается
- Wi-Fi упал: LAN-переходник, потом хотспот; локальная разработка продолжается, деплой позже; чекпоинт можно показать локально.
- Перк-ключ не работает: свой ключ в .env.local. В Vercel перк-ключ не кладём никогда, там всегда свой: перк могут отозвать после события, а эксперты проверяют живой URL 24–28.09.
- API-ключа нет вообще (перк оказался подпиской, своего аккаунта нет): `NVIDIA_API_KEY` из перков и `AGENT_MODEL` с build.nvidia.com; иначе режим просмотра, README честно пишет «без ключа агент недоступен», доказательство работы цикла это тесты на мок-модели и verify, балл за реализацию ниже.
- Деплой падает: чинить до 20 минут, потому что живой URL это путь проверки для судьи без ключа. Не поднялся: это прямой риск недопуска по п. 5.6.6 — проверка ключевой функциональности должна идти без наших аккаунтов и ключей. Тогда в README честно: локальный запуск основной путь, и обязательно дать тестовый ключ или другой способ проверки.
- Turso не заводится: это НЕ «одна строка в ограничениях». Без Turso на Vercel у каждого экземпляра функции своя база в памяти: запись идёт в одном, страница перерисовывается в другом, эксперт жмёт Approve и видит, что строка не изменилась — недопуск по п. 5.4.16. Чинить до 15 минут (новый токен, заново `vercel env add`). Не завелось: в README основной путь проверки — локальный запуск со своим ключом, живой URL помечен «только просмотр», и это прямо написать.
- Агент не проходит сценарий за 6 шагов: упростить цель по умолчанию, уменьшить сид, не расширять инструменты.
- Codex или Claude Code «зависает» на задаче дольше 15 минут: новая сессия, задачу разбить пополам.
